# Parallel-Implementation-of-Biorthogonal-Singular-Value-Decomposition-SVD-
This project presents a parallelized implementation of the Biorthogonal Singular Value Decomposition (SVD) using OpenMP. The biorthogonal SVD is an iterative algorithm based on Givens rotations that progressively orthogonalizes a matrix. It is useful in various applications such as signal processing, noise reduction, and linear system solving. 
We compare the serial vs parallel implementations in terms of performance across different matrix sizes and thread counts, showcasing the benefits of parallelization.
